# XiangGuangxuan.github.io

这是一个可以发布到 GitHub Pages 的静态个人主页。

## 文件说明

- `index.html`：网页内容和结构
- `styles.css`：网页样式
- `script.js`：简单交互

## 发布方式

把代码推送到 `main` 分支后，GitHub Pages 通常会自动发布：

```text
https://XiangGuangxuan.github.io/
```

如果没有自动发布，可以到 GitHub 仓库的 `Settings` -> `Pages` 中选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/root`。
